# ScribeRelay constitution — proposed

Derived from AGENTS.md, product vision, PRD and accepted working governance; no conflicting or superseding authority intended. Owner approval required for changes.

1. Author intent and accountability: every source inventory element is preserved, transformed with disclosure, manual, unsupported or unknown; zero silent loss. Reject inputs if accounting is unreliable.
2. Local-first and safety: no mandatory account, upload, server or AI for conversion; treat inputs as untrusted; sanitize, enforce resource limits, avoid implicit external fetches and document telemetry risks.
3. User-controlled publishing: no undocumented API, scraping or editor automation; actual paste and reopened draft evidence is required for destination support.
4. Evidence before commitment: distinguish proposed/accepted/validated/deferred; stack and architecture need owner approval; unknown does not mean unsupported or preserved.
5. Independently verifiable slices: deterministic conversion, source/destination separation, acceptance scenarios and traceable tests. No production code until M2/M5 approval and M6 readiness.
6. Reviewable delivery: GitHub as source of truth, feature branches and PRs, no direct main writes/force pushes, owner approval to merge and release.
7. Minimum scope: LinkedIn Articles MVP only; P1 and future destinations conditional; avoid speculative infrastructure.

Every spec and plan must demonstrate compliance or request an explicit owner-approved amendment. Preserve existing repository protections. Isolated approved synthetic feasibility experiments are exempt from the production implementation gate, not from safety or evidence rules.
