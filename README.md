# ScribeRelay

**Write anywhere. Publish everywhere. Preserve your intent.**

ScribeRelay is a proposed destination-aware publishing companion for transferring existing authored documents into publication-ready content without silently losing content or formatting.

**Author anywhere → Relay faithfully → Publish anywhere**

## Initial direction
- Import Markdown, Word (.docx), and rich text.
- Normalize content, preview destination-specific transformations, and report compatibility issues.
- Prepare rich-text clipboard output for LinkedIn Articles; assist with media that requires manual placement.
- Keep the author in control of final pasting, draft saving and publication.

LinkedIn Articles is the first destination. Native draft creation, automatic publishing, and other destinations are not commitments for the MVP.

## Project status
Documentation-first discovery; no application implementation. ScribeRelay is an accepted working name, not a cleared public brand. The repository is private; licensing is undecided.
