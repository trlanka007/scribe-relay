## Governance
- **Proposed:** awaits owner review.
- **Accepted:** explicitly agreed by the owner.
- **Validated:** supported by recorded experiments, with scope and limitations.
- **Deferred:** deliberately outside the current scope.
- Unknown or undocumented is not equivalent to unsupported.

GitHub is the source of truth. Use branches and pull requests; merge only with owner approval. Record decisions, evidence, assumptions and unresolved questions separately. Do not treat roadmap features as implemented or select a technology stack before evaluating requirements. Do not start implementation before requirements and architecture reviews.
